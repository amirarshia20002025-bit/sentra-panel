# SENTRA Panel — پنل پروکسی شخصی روی یک Worker رایگان کلودفلر

**SENTRA** پیاده‌سازی‌ای **کاملاً اصلی** (بدون کوچک‌ترین کپی از کد پروژه‌های دیگر) از یک پنل مدیریت پروکسی ضدسانسور روی Cloudflare Workers است که ترکیب بهترین امکانات این کلاس از پنل‌ها را در یک کد خوانا و قابل توسعه (مجوز MIT) گرد آورده است. فرمت‌های پروتکل از مشخصات عمومی خود پروتکل‌ها (XTLS، trojan-gfw، Shadowsocks AEAD، SIP002/003، RFC 6238) پیاده شده‌اند.

- **یک Worker واحد، پلن رایگان، بدون VPS و بدون سرور مبدأ** — همه‌چیز از دامنه خودتان سرو می‌شود.
- **دیتابیس D1 + کش KV**، پنل فارسی راست‌به‌چپ با تم تیره/روشن، حالت ساده و پیشرفته.
- **امنیت پنل:** رمز PBKDF2، ورود دومرحله‌ای TOTP با کدهای بازیابی، محدودیت تلاش ورود (۵ تلاش در ۱۵ دقیقه)، نشست‌های کوکی HttpOnly + CSRF، ویزارد نصب با توکن claim که مالکیت Worker را به شما گره می‌زند.

## 🚀 نصب

### پیش‌نیاز
حساب رایگان Cloudflare + Node.js 18+ و Wrangler.

### روش A: Wrangler (توصیه‌شده)
```bash
npm install
# ساخت منابع:
npx wrangler d1 create sentra-db
npx wrangler kv namespace create KV
# شناسه‌ها را در wrangler.toml بگذارید، سپس:
npm run db:init:remote
npm run deploy
```
سپس `https://<your-worker>.workers.dev/install` را باز کنید؛ **توکن claim فقط یک‌بار نمایش داده می‌شود** — آن را در فرم همین صفحه وارد کرده و رمز ادمین بسازید. کدهای بازیابی و کلید TOTP که بعد از نصب نشان داده می‌شود را همان لحظه ذخیره کنید.

### روش B: بدون کامپیوتر
همان مخزن را در گیت‌هاب خود فورک کنید، دکمه Deploy to Cloudflare بزنید و بعد از دیپلوی با مرورگر گوشی به `/install` بروید.

### اتصال ربات
1. در پنل (تنظیمات → ربات) توکن ربات را از @BotFather بگذارید.
2. وب‌هوک را تنظیم کنید: `https://<your-worker>/bot/<BOT_PATH_SECRET>` (مقدار BOT_PATH_SECRET را در wrangler.toml عوض کنید!).
3. در ربات: `/claim توکن-نصب` را بفرستید تا مالک شوید.

## 🕶 نسخه obfuscate شده (worker.js تک‌فایل)

اگر خروجی نهایی را بدون خوانا بودن می‌خواهید، همین سورس قابل تبدیل به یک باندل مبهم‌سازی‌شده است:

```bash
npm i               # esbuild + javascript-obfuscator (devDependencies)
npm run obfuscate   # → dist/worker.js
```

خط تولید: باندل esbuild (۱۴ ماژول → یک فایل؛ `cloudflare:sockets` خارج از باندل حفظ می‌شود و فایل `.txt` کتابخانه QR به‌صورت متن جاسازی می‌شود) و سپس javascript-obfuscator با گزینه‌های سازگار با Workers — بدون `eval` / `new Function` / `debugger`، چون Workers کدنویسی داینامیک را مسدود می‌کند. اسکریپت در پایان، نبودن الگوهای ممنوعه و حفظ import را به‌صورت خودکار بررسی می‌کند.

برای دیپلوی این نسخه، `main` را در wrangler.toml به `dist/worker.js` تغییر دهید. حجم معمول: باندل خوانا ~۲۰۰KB → نسخه مبهم ~۶۴۰KB (زیر سقف ۱MB پلن رایگان). یک نسخه از پیش ساخته‌شده با کانفیگ و راهنمای جداگانه در پوشه `sentra-panel-obf` کنار این مخزن تحویل شده است.

یادآوری واقع‌بینانه: obfuscation خوانایی کد را حذف می‌کند، نه رفتار قابل‌مشاهده از ترافیک شبکه را؛ همه secretها مثل همیشه در D1/KV زندگی می‌کنند، نه در کد.

## 📡 آینه گیت‌هاب (بقای لینک پس از فیلتر دامنه)

در پنل، مخزن خود را در «عملیات → آینه گیت‌هاب» ثبت کنید، سپس در آن مخزن یک Action با این مضمون بسازید که هر روز محتوای اشتراک را push کند (توکن‌ها در Secrets):

```yaml
name: Mirror subscription
on:
  schedule: [{cron: "0 */6 * * *"}]
  workflow_dispatch:
jobs:
  mirror:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: |
          curl -fsS "${{ secrets.SUB_URL }}" -o sub.txt
          git config user.email bot@users.noreply.github.com
          git config user.name mirror-bot
          git commit -am "mirror $(date -u +%F)" || exit 0
          git push
```

کاربران شما لینک `https://raw.githubusercontent.com/<owner>/<repo>/main/sub.txt` را به‌عنوان لینک پشتیبان دارند.

## 🧪 تست و توسعه محلی

```bash
npm test          # ۴۳ تست منطق خالص: MD5، SHA-224، TOTP، فریمر gRPC، سازنده نود، فرمت‌ها
npm run dev       # wrangler dev — اجرای کامل روی لوکال (شبیه‌سازی D1/KV)
```

> نکته: ماژول رله از `cloudflare:sockets` استفاده می‌کند که فقط در محیط Workers/`wrangler dev` بارگذاری می‌شود؛ به همین دلیل تست‌های Node فقط منطق خالص را پوشش می‌دهند و آزمون نهایی اتصال باید با `wrangler dev` و یک کلاینت واقعی انجام شود.

## ⚠️ محدودیت‌های صادقانه

- **UDP/تماس‌ها:** حمل‌ونقل WebSocket روی Workers پروتکل TCP دارد؛ VLESS/Trojan روی WS فقط فرمان TCP را رله می‌کنند. برای UDP و تماس‌ها از خروجی WARP/WireGuard (به‌عنوان تونل کلاینت) یا زنجیره روی VPS شخصی استفاده کنید.
- **محدودیت IP:** روی Edge حالت چسبنده نیست؛ اجرای سقف دستگاه با کلیدهای TTL در KV است (پنجره ۳۰ دقیقه) — دقیق اما نه لحظه‌ای.
- **حسابداری مصرف:** بافر محلی هر isolate است و با Cron به D1 تفت داده می‌شود؛ بلافاصله قبل از فلاش، خطای کوچک طبیعی است.
- **gRPC (آزمایشی):** فریمینگ استاندارد است، اما Workers نمی‌تواند HTTP trailer بفرستد؛ یعنی پایان استریم بدون تریلر `grpc-status` اعلام می‌شود و بعضی کلاینت‌ها در لحظه بستن، EOF لاگ می‌کنند (داده‌ها کامل تحویل شده‌اند). گره‌های WS را به‌عنوان گزینه اصلی نگه دارید.
- **XHTTP (آزمایشی):** بر اساس طراحی SplitHTTP (GET دانلود + POST آپلود با شناسه نشست در مسیر) و رجیستری نشست در همان isolate است؛ در صورت پراکندگی بین isolate ها نشست می‌تواند بشکند — برای پایداری، WS توصیه‌شده است.
- **حالت Backend روی VPS:** این مخزن فقط زنجیره/کندادیل تولید می‌کند؛ سرور Xray/sing-box روی VPS را خودتان اجرا کنید و به‌عنوان یک chain تعریف کنید.

## 🔐 نکات امنیتی

- مقدار `BOT_PATH_SECRET` در wrangler.toml را حتماً عوض کنید.
- بکاپ JSON شامل رمز ادمین و کلید TOTP است — مثل رمز عبور نگه‌داریش کنید.
- لینک اشتراک هر کاربر یک اعتبارنامه است؛ چرخش (🔄) همه اعتبارنامه‌های آن کاربر را باطل می‌کند.
